# Learning_Backend

Self-contained, interactive HTML lessons on how backend systems work. Each file
runs in the browser with no build step — just open it.

## Lessons

- **[Frontend vs backend interactive lesson.html](Frontend%20vs%20backend%20interactive%20lesson.html)** —
  Front of house / back of house: what actually runs on the user's device versus
  on a server you control, why the client can never be trusted with secrets, a
  walkthrough of a login request, and common beginner mistakes.
- **Lesson 01 what is backend.HTML** — placeholder, not written yet.

## Viewing

Clone and open a file directly, or browse the rendered pages via GitHub Pages if
enabled for this repo.

```sh
git clone https://github.com/Maltipat/Learning_Backend.git
open "Learning_Backend/Frontend vs backend interactive lesson.html"
```
